    Run the migration command to create an empty migration scaffold:

    ```bash
    dotnet ef migrations add SeedBlankRecipe \
      --project IronMonkey.Data \
      --startup-project IronMonkey.ApiService \
      --context CentralDbContext \
      --output-dir Migrations/Central
    ```

    After generation, open the generated `[timestamp]_SeedBlankRecipe.cs` file. The Up() and Down() methods will be empty — manually add the seed data:

    In the `Up` method, add:
    ```csharp
    var blankRecipeId = new Guid("00000000-0000-0000-0000-000000000001");
    var now = new DateTime(2026, 1, 1, 0, 0, 0, DateTimeKind.Utc);
    var contentJson = "{\"PipelineStages\":[{\"Name\":\"New\",\"Order\":0,\"StageType\":\"Entry\"}],\"CustomFields\":[],\"WorkflowRules\":[],\"Roles\":[]}";

    migrationBuilder.InsertData(
        table: "industry_recipes",
        columns: new[] { "Id", "Name", "Description", "IndustrySlug", "IconIdentifier", "IsBlank", "IsActive", "Version", "ContentJson", "CreatedAt", "UpdatedAt", "IsDeleted" },
        values: new object[] { blankRecipeId, "Blank/Custom", "Start with a clean workspace. One default pipeline stage included.", "blank", "icon-blank", true, true, 1, contentJson, now, now, false });
    ```

    In the `Down` method, add:
    ```csharp
    migrationBuilder.DeleteData(
        table: "industry_recipes",
        keyColumn: "Id",
        keyValue: new Guid("00000000-0000-0000-0000-000000000001"));
    ```

    The fixed GUID `00000000-0000-0000-0000-000000000001` makes the blank recipe ID predictable for provisioning code and tests.

    CRITICAL: JSON keys must be PascalCase (`"PipelineStages"`, `"Name"`, `"Order"`, `"StageType"`, `"CustomFields"`, `"WorkflowRules"`, `"Roles"`). System.Text.Json deserializes using PascalCase by default to match C# property names on RecipeContentModel. camelCase keys would produce empty lists after deserialization in TenantProvisioningService.
