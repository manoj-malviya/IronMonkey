**CustomFieldValues.cs** — JSON complex type owned by Lead:
```csharp
namespace IronMonkey.Data.Entities;
public class CustomFieldValues
{
    public Dictionary<string, object?> Values { get; set; } = new();
    public void Set(string fieldId, object? value) => Values[fieldId] = value;
    public object? Get(string fieldId) => Values.TryGetValue(fieldId, out var val) ? val : null;
}
```
Note: Use `Dictionary<string, object?>` (string keys, not Guid) — EF Core 10 JSON serialization handles string-keyed dictionaries correctly; Guid keys require custom converters.
