  <action>
Create the Features/Leads directory structure. Implement 5 endpoints following the `IEndpoint` pattern.

**CreateCustomFieldEndpoint.cs** — POST /api/custom-fields:
- Request: `{ fieldName: string, fieldType: string, isRequired: bool, options: string[] }`
- Parse fieldType string to `CustomFieldType` enum; return 400 if invalid
- If fieldType is Dropdown or MultiSelect, require options.Count > 0; return 400 if missing
- Call `CustomFieldDefinition.Create(tenantId, fieldName, type, isRequired, options)`
- SaveChangesAsync, return 201 with `{ id, fieldName, fieldType, isRequired, options }`
- Requires auth (`.RequireAuthorization()`)

**ListCustomFieldsEndpoint.cs** — GET /api/custom-fields:
- Query `db.CustomFieldDefinitions.OrderBy(c => c.FieldName).ToListAsync()`
- Query filter in TenantDbContext enforces tenant isolation automatically
- Return 200 with array of `{ id, fieldName, fieldType, isRequired, options }`

**CreatePipelineStageEndpoint.cs** — POST /api/pipeline-stages:
- Request: `{ name: string, order: int }`
- Validate: name not empty (max 100 chars), order > 0
- Check for unique order within tenant: if duplicate order exists, return 409 Conflict
- Call `PipelineStage.Create(tenantId, name, order)`
- SaveChangesAsync, return 201 with `{ id, name, order, isActive }`

**ListPipelineStagesEndpoint.cs** — GET /api/pipeline-stages:
- Query `db.PipelineStages.OrderBy(p => p.Order).ToListAsync()`
- Query filter handles TenantId + IsActive automatically (from Plan 02 configuration)
- Return 200 with array of `{ id, name, order, isActive }`

**UpdatePipelineStageEndpoint.cs** — PUT /api/pipeline-stages/{id}:
- Request: `{ name: string, order: int }`
- Load stage by id — if not found (or wrong tenant), return 404
- Validate new order is unique within tenant (exclude current stage from uniqueness check)
- Call `stage.Update(name, order)`, SaveChangesAsync
- Return 200 with updated `{ id, name, order, isActive }`

All endpoints: inject `ITenantService` and `TenantDbContext` (resolved from service container via `ITenantService.GetTenantDbContextAsync()`). Add `.RequireAuthorization()` to each route.
