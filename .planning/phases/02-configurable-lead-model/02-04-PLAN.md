```csharp
public record DuplicateCandidate(Guid LeadId, string FullName, string Email, string Reason, int ConfidenceScore);
public interface IDuplicateDetectionService
{
    Task<List<DuplicateCandidate>> FindCandidatesAsync(
        Guid tenantId, string? email, string? phone, string? name, CancellationToken ct = default);
}
```

**DuplicateDetectionService.cs**:
- Inject `TenantDbContext` (resolved via `ITenantService.GetTenantDbContextAsync()` — inject ITenantService instead of TenantDbContext directly since service is transient)
- Inject `ITenantService`
- Phone normalization: `Regex.Replace(phone, @"\D", "")` — strip non-digits
- Email normalization: `.Trim().ToLower()`
- Exact email match: `db.Leads.Where(l => l.Email.ToLower() == normalizedEmail)` — confidence 100
- Exact phone match: `db.Leads.Where(l => ...)` — compare Mobile after both normalized — confidence 95
- Fuzzy name match: only when candidates.Count == 0 and name provided — load all leads, apply `FuzzySharp.Fuzz.TokenSetRatio(name, fullName) >= 75` in memory — confidence = score
- Use `IgnoreQueryFilters()` when loading for fuzzy — but scope to `l.TenantId == tenantId && !l.IsDeleted` explicitly (do NOT expose cross-tenant data — the manual filter is safer than relying on global filter during fuzzy load)
- Return `candidates.OrderByDescending(c => c.ConfidenceScore).ToList()`

- Request: `{ email?: string, phone?: string, name?: string }`
- Call `IDuplicateDetectionService.FindCandidatesAsync(tenantId, email, phone, name)`
- Return 200 with `{ candidates: [{ leadId, fullName, email, reason, confidenceScore }] }`
- If request has no fields provided, return 400 "At least one of email, phone, or name is required"
- Requires auth

**ILeadMergeService.cs**:
```csharp
public interface ILeadMergeService
{
    Task<Lead> MergeAsync(Guid tenantId, Guid sourceLeadId, Guid targetLeadId, Guid userId, CancellationToken ct = default);
}
```

**LeadMergeService.cs**:
- Inject `ITenantService`
- Load source and target leads; throw `KeyNotFoundException` if either not found
- If sourceLeadId == targetLeadId, throw `ArgumentException("Cannot merge a lead with itself")`
- Merge custom fields: for each entry in target.CustomFields.Values, if source does NOT have that key OR source value is null, call `source.CustomFields.Set(key, value)`
- Serialize snapshots BEFORE mutation: `JsonSerializer.Serialize(new { source.Email, source.FirstName, source.LastName, source.CustomFields.Values })`
- Soft-delete target: `target.IsDeleted = true; target.DeletedAt = DateTime.UtcNow;`
- Create audit: `LeadMerge.Create(tenantId, sourceLeadId, targetLeadId, userId, sourceSnapshot, targetSnapshot)`
- `db.Add(mergeRecord)` then `await db.SaveChangesAsync(ct)`
- Return source lead

**MergeLeadsEndpoint.cs** — POST /api/leads/{id}/merge:
- Route param `id` = sourceLeadId (the surviving lead)
- Request body: `{ targetLeadId: Guid }`
- Validate: id != targetLeadId (400 if same)
- Call `ILeadMergeService.MergeAsync(tenantId, id, targetLeadId, userId)`
- Catch `KeyNotFoundException` → 404
- Catch `ArgumentException` → 400 with message
- Return 200 with merged lead `{ id, firstName, lastName, email, source, pipelineStageId, customFields }`
- Requires auth
