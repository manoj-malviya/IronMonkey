  </read_first>

  <action>
1. Create `IronMonkey.Web/wwwroot/css/input.css` with this exact content:
   ```css
   @import "tailwindcss";
   ```
   No additional directives needed — Tailwind v4 auto-scans all .razor files via `@import "tailwindcss"`.

2. Add a `.gitignore` entry (or create `IronMonkey.Web/wwwroot/css/.gitignore`) to ignore the generated output:
   ```
   output.css
   ```

3. Add the following MSBuild target to `IronMonkey.Web/IronMonkey.Web.csproj`, inside the `<Project>` element but AFTER the existing `<ItemGroup>` blocks:
   ```xml
   <Target Name="BuildTailwindCSS" BeforeTargets="Build">
     <Exec Command="tailwindcss --input wwwroot/css/input.css --output wwwroot/css/output.css --minify" />
   </Target>
   ```
   This runs `tailwindcss` (must be on PATH) before the C# build. The `--minify` flag produces a smaller output in all build configurations. No config file needed — Tailwind v4 auto-detects .razor content.

4. Also add an `<ItemGroup>` to exclude the generated output.css from static asset fingerprinting (prevents stale cache):
   ```xml
   <ItemGroup>
     <Content Remove="wwwroot/css/output.css" />
     <Content Include="wwwroot/css/output.css">
       <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
     </Content>
   </ItemGroup>
   ```
  </action>

  </verify>

2. Update `IronMonkey.AppHost/AppHost.cs` to add the Web project. After the `apiService` variable declaration, add:
   ```csharp
   var webFrontend = builder.AddProject<Projects.IronMonkey_Web>("webfrontend")
       .WithReference(apiService)
       .WaitFor(apiService)
       .WithExternalHttpEndpoints();
   ```
   The complete AppHost.cs should look like:
   ```csharp
   var builder = DistributedApplication.CreateBuilder(args);

   var postgres = builder.AddPostgres("postgres");
   var centralDb = postgres.AddDatabase("CentralDb");

   var apiService = builder.AddProject<Projects.IronMonkey_ApiService>("apiservice")
       .WithReference(centralDb)
       .WaitFor(centralDb)
       .WithHttpHealthCheck("/health");

   var webFrontend = builder.AddProject<Projects.IronMonkey_Web>("webfrontend")
       .WithReference(apiService)
       .WaitFor(apiService)
       .WithExternalHttpEndpoints();

   builder.Build().Run();
   ```
   Note: `Projects.IronMonkey_Web` is the auto-generated Aspire project reference class matching the project name `IronMonkey.Web`. `.WithExternalHttpEndpoints()` ensures the Aspire dashboard shows a clickable URL for the web frontend.
