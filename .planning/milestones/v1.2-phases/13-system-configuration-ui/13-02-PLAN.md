    **@code block methods:**

    - `OnInitializedAsync`: call `LoadStagesAsync()`
    - `SetTab(string tab)`: set `_activeTab = tab`. If switching to "Pipeline Stages" and `!_stagesLoaded`, call `LoadStagesAsync()`.
    - `LoadStagesAsync()`: set `_isLoading = true`, GET `/api/pipeline-stages`, deserialize to `List<StageItem>`, sort by Order, set `_stagesLoaded = true`, `_isLoading = false`. Catch exceptions → `_errorBanner`.
    - `StartAddStage()`: set `_creatingStage = true`, `_editingStageId = null`, `_newStageName = ""`, `_newStageType = "Active"`
    - `CancelAddStage()`: set `_creatingStage = false`
    - `SaveNewStageAsync()`: POST `/api/pipeline-stages` with `{ Name = _newStageName, Order = _stages.Count + 1, StageType = _newStageType }`. On success, add to `_stages`, re-sort, set `_creatingStage = false`, show success message "Pipeline stage created.". On error, set `_errorBanner`.
    - `StartEditStage(StageItem stage)`: set `_editingStageId = stage.Id`, `_editingStage = new StageItem { Id = stage.Id, Name = stage.Name, Order = stage.Order, StageType = stage.StageType }`, `_creatingStage = false`
    - `CancelEditStage()`: set `_editingStageId = null`, `_editingStage = null`
    - `SaveEditStageAsync()`: PUT `/api/pipeline-stages/{_editingStageId}` with `{ Name = _editingStage.Name, Order = _editingStage.Order }`. On success, update in `_stages`, clear editing state, show "Pipeline stage saved.". On error, set `_errorBanner`.
    - `MoveStageUpAsync(Guid id)`: find stage and stage above, swap Order values, fire 2x PutAsJsonAsync in parallel. On error, restore orders and set `_errorBanner`. On success show "Stages reordered." and re-sort list.
    - `MoveStageDownAsync(Guid id)`: same but with stage below.
    - `OpenDeleteStageConfirm(Guid id)`: set `_showDeleteConfirm = true`, `_deleteModalTitle = "Delete Pipeline Stage"`, `_deleteModalMessage = "Are you sure? Leads in this stage will be affected. This cannot be undone."`, `_deletingItemId = id`, `_deletingItemType = "stage"`
    - `CancelDelete()`: `_showDeleteConfirm = false`
    - `ConfirmDeleteAsync()`: dispatch to the right delete handler based on `_deletingItemType`. For "stage": DELETE `/api/pipeline-stages/{_deletingItemId}`, remove from `_stages`, show "Pipeline stage deleted.".
    - `ShowSuccessMessage(string msg)`: set `_successMessage = msg`, fire and forget `Task.Run(async () => { await Task.Delay(3000); _successMessage = null; await InvokeAsync(StateHasChanged); })`
