    **New methods to add:**
    - `LoadFieldsAsync()`: GET `/api/custom-fields`, deserialize to `List<FieldItem>`, set `_fieldsLoaded = true`

    - `StartEditField(FieldItem f)`: set `_editingFieldId = f.Id`, `_editingField = new FieldItem { ... copy }`, `_creatingField = false`. Also set `_editingFieldOptions = string.Join(", ", f.Options)`.
    - `CancelEditField()`: clear `_editingFieldId`, `_editingField`
    - `SaveEditFieldAsync()`: PUT `/api/custom-fields/{_editingFieldId}` with updated FieldName, FieldType, IsRequired, Options. On success update in list, clear editing, show "Custom field saved.".
    - `OpenDeleteFieldConfirm(Guid id)`: set modal fields with title "Delete Custom Field", message "Are you sure? Data in this field cannot be recovered.", `_deletingItemType = "field"`, `_deletingItemId = id`
    - `ParseOptions(string raw)`: `return string.IsNullOrWhiteSpace(raw) ? new List<string>() : raw.Split(',').Select(s => s.Trim()).Where(s => !string.IsNullOrEmpty(s)).ToList();`
    - Extend `ConfirmDeleteAsync()` with: `"field" => DELETE /api/custom-fields/{_deletingItemId}, remove from _fields, show "Custom field deleted."`
    - Extend `SetTab()` to call `LoadFieldsAsync()` when switching to "Custom Fields" and `!_fieldsLoaded`
