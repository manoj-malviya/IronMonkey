    **New methods to add:**
    - `LoadRulesAsync()`: GET `/api/workflow-rules`, deserialize to `List<RuleItem>`, set `_rulesLoaded = true`. Catch → `_errorBanner`.
    - `StartAddRule()`: set `_creatingRule = true`, `_editingRuleId = null`, reset `_newRule*` fields to defaults
    - `CancelAddRule()`: set `_creatingRule = false`
    - `SaveNewRuleAsync()`: POST `/api/workflow-rules` with `{ Name = _newRuleName, Trigger = _newRuleTrigger, ConditionJson = _newRuleConditionJson, ActionJson = _newRuleActionJson }`. On success, add to `_rules`, cancel add, show "Workflow rule created.". On error, `_errorBanner`.
    - `StartEditRule(RuleItem r)`: set `_editingRuleId = r.Id`, `_editingRule = new RuleItem { Id = r.Id, Name = r.Name, Trigger = r.Trigger, ConditionJson = r.ConditionJson, ActionJson = r.ActionJson, IsActive = r.IsActive }`, `_creatingRule = false`
    - `CancelEditRule()`: clear `_editingRuleId`, `_editingRule`
    - `SaveEditRuleAsync()`: PUT `/api/workflow-rules/{_editingRuleId}` with `{ Name = _editingRule.Name, Trigger = _editingRule.Trigger, ConditionJson = _editingRule.ConditionJson, ActionJson = _editingRule.ActionJson }`. On success update in `_rules`, clear editing state, show "Workflow rule saved.".
    - `ToggleRuleActiveAsync(Guid id)`: POST `/api/workflow-rules/{id}/toggle` with no body (empty `StringContent`). On success find rule in `_rules` and flip `IsActive` in-place, show "Rule is now [active/inactive].". On error set `_errorBanner`.
    - `OpenDeleteRuleConfirm(Guid id)`: set `_showDeleteConfirm = true`, `_deleteModalTitle = "Delete Workflow Rule"`, `_deleteModalMessage = "Are you sure? This rule will no longer execute."`, `_deletingItemType = "rule"`, `_deletingItemId = id`
    - Extend `ConfirmDeleteAsync()` with: `"rule" => DELETE /api/workflow-rules/{_deletingItemId}, remove from _rules, show "Workflow rule deleted."`
    - Extend `SetTab()`: when switching to "Workflow Rules" and `!_rulesLoaded`, call `LoadRulesAsync()`
