<!-- Backend API contracts — verified from source -->

GET /api/recipes/{id} → RecipePreviewEndpoint.Response | NotFound
Response: { Guid Id, string Name, string Description, RecipeContentModel Content }
Note: Only returns IsActive=true recipes. If recipe is deactivated, returns 404.
Note: Response does NOT include IconIdentifier, IndustrySlug, IsBlank, Version — these must be fetched separately OR the edit form fetches from a different source.

IMPORTANT: The preview endpoint (RecipePreviewEndpoint) returns only Id, Name, Description, Content. It does NOT return IconIdentifier, IndustrySlug, IsBlank, or Version. For RecipeEdit, the form needs Name, Description, IconIdentifier, IndustrySlug, IsBlank in addition to Content. This is a gap — there is no endpoint that returns all metadata fields together with content.

Resolution for RecipeEdit:
- Fetch from GET /api/recipes/{id} to get Name, Description, Content
- Fetch from GET /api/recipes (list) to find the matching recipe for IconIdentifier, IndustrySlug, IsBlank, Version
- On init: call both endpoints, merge results into the form model
- Alternatively: prefill IconIdentifier="" and IndustrySlug="" from content (suboptimal) — but the list endpoint returns these fields, so fetching the list is better

PUT /api/recipes/{id}
Request body (UpdateRecipeEndpoint.Request):
  RecipeContentModel Content
Response on 200: { Guid RecipeId, int NewVersion, string Message }
Response on 404: NotFound
Response on 400: ValidationError
Response on 401: Unauthorized

Note: PUT /api/recipes/{id} only updates Content — NOT Name, Description, IconIdentifier, IndustrySlug, IsBlank. The backend UpdateRecipeEndpoint.Request only accepts RecipeContentModel Content. Metadata fields cannot be updated via PUT in the current API.

Resolution for RecipeEdit form:
- Show metadata fields (Name, Description, etc.) as read-only display with note "Recipe metadata cannot be edited after creation"
- Allow editing only the Content sections (stages, fields, rules, roles) via RecipeContentEditor
- Save button calls PUT /api/recipes/{id} with only the Content

RecipeContentModel structure (from RecipeContentModel.cs):
  PipelineStages: List<PipelineStageDefinition> — Name, Order, StageType
  CustomFields: List<CustomFieldDefinitionDto> — FieldName, FieldType, IsRequired, Options
  WorkflowRules: List<WorkflowRuleDefinition> — Name, Trigger, ConditionJson, ActionJson
  Roles: List<RoleDefinition> — Name, Description
  SampleLeads: List<SampleLeadDefinition> — not shown in editor

RecipeContentEditor component (from Plan 02):
  Parameter: RecipeContentModel Content (EditorRequired)
  Parameter: EventCallback OnChanged

**OnInitializedAsync:**
```csharp
protected override async Task OnInitializedAsync()
{
    _isLoading = true;
    try
    {
        var client = HttpClientFactory.CreateClient("AdminApi");

        // Fetch full recipe content
        var preview = await client.GetFromJsonAsync<RecipePreviewDto>($"/api/recipes/{Id}");
        _recipe = preview;
        if (preview is not null)
            _content = preview.Content ?? new RecipeContentModel();

        // Fetch metadata (IndustrySlug, IconIdentifier, IsBlank, Version) from list endpoint
        var list = await client.GetFromJsonAsync<List<RecipeListItem>>("/api/recipes");
        _listItem = list?.FirstOrDefault(r => r.Id == Id);
    }
    catch (Exception ex)
    {
        _errorBanner = $"Failed to load recipe: {ex.Message}";
    }
    finally
    {
        _isLoading = false;
    }
}
```

**HandleSaveAsync:**
```csharp
private async Task HandleSaveAsync()
{
    _isSaving = true;
    _errorBanner = null;
    _successMessage = null;

    try
    {
        var client = HttpClientFactory.CreateClient("AdminApi");
        var payload = new { Content = _content };
        var response = await client.PutAsJsonAsync($"/api/recipes/{Id}", payload);

        if (response.IsSuccessStatusCode)
        {
            var result = await response.Content.ReadFromJsonAsync<RecipeUpdateResponse>();
            _successMessage = $"Recipe saved. Version: v{result?.NewVersion}";
            // Refresh list item to show updated version
            if (_listItem is not null && result is not null)
                _listItem = _listItem with { Version = result.NewVersion };
        }
        else if (response.StatusCode == System.Net.HttpStatusCode.Unauthorized)
        {
            Nav.NavigateTo("/login");
        }
        else if (response.StatusCode == System.Net.HttpStatusCode.NotFound)
        {
            _errorBanner = "Recipe not found or has been deactivated.";
        }
        else
        {
            var errorBody = await response.Content.ReadAsStringAsync();
            _errorBanner = $"Failed to save: {errorBody}";
        }
    }
    catch (Exception ex)
    {
        _errorBanner = $"Unable to save recipe: {ex.Message}";
    }
    finally
    {
        _isSaving = false;
    }
}
```
