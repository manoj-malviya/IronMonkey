## Spacing Scale

Declared values (all multiples of 4px):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, fine-tuning |
| sm | 8px | Compact element spacing, form field margins |
| md | 16px | Default element spacing, form field padding |
| lg | 24px | Section padding (features grid vertical) |
| xl | 32px | Layout gaps (hero to features section break) |
| 2xl | 48px | Major section breaks, feature card vertical padding |
| 3xl | 64px | Page-level horizontal padding, hero min-height spacing |

Exceptions: None

**Source:** Login.razor pattern established (px-4 = 16px, py-6 = 24px, py-10 = 40px). Standards inherited from existing admin UI.

## Typography

Declared roles and specs:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (normal) | 1.5 | Feature descriptions, copy, footer text |
| Label | 14px | 500 (medium) | 1.4 | Feature card titles, button labels, nav text |
| Heading | 28px | 700 (bold) | 1.2 | Hero tagline "Manage Every Lead, Your Way" |
| Display | 36px | 700 (bold) | 1.1 | Future use (not in Phase 14) |

**Heading usage specifics:**
- Hero tagline: 28px bold, white text on dark gradient
- Feature card titles: 20px semibold (font-semibold), slate-900 on white background

**Source:** Login.razor establishes weight patterns (text-3xl font-bold = 30px bold for "IronMonkey", text-sm = 14px, text-xl = 20px semibold). Heading line height 1.2 is SaaS standard for readability.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | white / rgb(255, 255, 255) | Features section background, feature cards, footer background |
| Secondary (30%) | indigo-600 / rgb(79, 70, 229) | CTA buttons (filled), dark hero gradient base, accent borders |
| Accent (10%) | indigo-400 / rgb(129, 140, 248) | CTA button hover states, gradients, subtle emphasis |
| Destructive | red-600 / rgb(220, 38, 38) | Not applicable in Phase 14 |
| Dark Base (hero) | slate-900 / rgb(15, 23, 42) | Hero section dark background (gradient start) |
| Text on Dark | white / rgb(255, 255, 255) | Hero section copy, nav logo text |
| Text on Light | slate-900 / rgb(15, 23, 42) | Body copy, feature titles |
| Muted Text | slate-600 / rgb(71, 85, 105) | Feature descriptions, secondary labels |
| Border | slate-200 / rgb(226, 232, 240) | Feature card subtle borders (optional) |

**Accent reserved for:**
- Primary CTA button filled state (indigo-600)
- Primary CTA button hover state (indigo-500)
- Secondary CTA text link on-hover (indigo-600)
- Hero section gradient accent color (indigo-400 with 30% opacity in mesh/gradient decoration)

**Gradient specification (hero section):**
- Hero background: Linear gradient from `indigo-950` (rgb(30, 27, 75)) at top to `indigo-600` (rgb(79, 70, 229)) at bottom
- Mesh/overlay: Radial gradient circles using `indigo-400` with 20% opacity for depth
- Result: Dark, dramatic modern SaaS feel (reference: Linear, Vercel)

**Source:** Login.razor color patterns (indigo-600, slate-100, slate-900, white). Feature card pattern from MainLayout.razor (bg-slate-50 for backgrounds). Gradient hero is design decision D-08.

## Layout & Responsive Breakpoints

**Desktop (1280px+):**
- Hero section: Full viewport height (min-h-screen), centered flex layout, 2-column text + decoration split
- Feature grid: 2x2 grid, 4 equal cards, spacing-xl between cards
- Top nav: Sticky, flex row with logo left and "Sign In" link right, padding-lg on sides
- Overall max-width: 1280px container with margin-auto centering

**Tablet (768px):**
- Hero section: Centered single column, reduced font sizes (tagline 24px), full viewport height
- Feature grid: 2-column grid (2 cards per row), reduced card padding (lg instead of 2xl)
- Top nav: Same layout as desktop, reduced padding (md instead of lg)
- Horizontal padding: 16px (md)

**Mobile (375px):**
- Hero section: Centered single column, reduced font sizes (tagline 20px), min-h-screen
- Feature grid: 1-column stack (1 card per row)
- Top nav: Horizontal padding reduced to sm (8px)
- Button text might wrap; ensure touch target min 44px height

**Responsive implementation:** Tailwind utility classes (`md:`, `lg:`, `2xl:` prefixes) per existing Blazor project patterns.

## Component Inventory

### 1. PublicLayout.razor (New)
**Purpose:** Clean layout for public pages (Home, Login, Signup). No admin sidebar/topbar.

**Structure:**
```
<html>
  <head>...</head>
  <body>
    <TopNav /> (logo left, Sign In link right)
    <main>@Body</main>
    <footer>© 2026 IronMonkey...</footer>
  </body>
</html>
```

**Styling:** White body, footer text on dark background

**Usage:** Pages add `@layout PublicLayout` attribute

### 2. Home.razor (Replace existing)
**Purpose:** Public landing page at `/`

**Page title:** "IronMonkey — Manage Every Lead, Your Way"

**Sections:**
1. Hero section (dark gradient background with mesh decoration)
2. Feature grid (4 features in responsive layout)
3. Footer with copyright

### 3. TopNav (Public nav component)
**Purpose:** Header visible on all public pages

**Content:**
- Left: IronMonkey logo text (28px bold white on dark hero, slate-900 on light features/footer)
- Right: "Sign In" text link (14px medium, indigo-600 hover state)
- Sticky: position sticky to top, z-index to layer above sections

**Background:** Inherits section background color (dark on hero, white on features)

**Padding:** lg (24px) horizontal

### 4. FeatureCard.razor (Reusable)
**Purpose:** Displays a single feature with icon, title, description

**Props:**
- `Icon`: SVG HTML (Heroicon)
- `Title`: string (20px semibold, slate-900)
- `Description`: string (16px normal, slate-600)

**Background:** White card with subtle border (border-slate-200, rounded-lg)

**Padding:** 2xl (48px) vertical, lg (24px) horizontal

**Shadow:** shadow-sm (subtle depth)

## Implementation Notes

### Layout routing (from D-11, D-12)
- Create PublicLayout.razor with clean structure (no AdminSidebar, no AdminTopbar)
- Home.razor adds `@layout PublicLayout` directive
- Login.razor already uses implicit layout; verify it uses PublicLayout after refactor
- Signup.razor (Phase 15) will also use `@layout PublicLayout`

### Tailwind integration
- MSBuild target in IronMonkey.Web.csproj already runs `npx @tailwindcss/cli` on build
- All Tailwind utilities available in Razor class attributes
- No additional config required

### Hero background implementation
- Use `bg-gradient-to-b` from indigo-950 to indigo-600
- Overlay with `radial-gradient` circles (SVG or CSS) using indigo-400 at 20% opacity for mesh effect
- Consider `backdrop-blur` if performance allows, else simple gradient sufficient

### Navigation continuity
- Navbar background must match section background (dark on hero, light on features, dark on footer)
- Use conditional classes or separate nav components per section
- OR: Use sticky nav with background color change on scroll (JavaScript event listener)

### Next phase handoff (Phase 15)
- Link /signup to Signup.razor page (new, Phase 15 scope)
- Link /login to Login.razor (already exists)
- Ensure login/signup cross-linking per NAV-02 requirement (deferred to Phase 15)
