**Step A — Create the Shared directory and FeatureCard.razor:**

Create IronMonkey.Web/Components/Shared/FeatureCard.razor:

```razor
@* Reusable feature card for the landing page feature grid *@

<div class="bg-white border border-slate-200 rounded-lg shadow-sm px-6 py-12">
    <div class="flex flex-col gap-4">
        <!-- Icon (24px, indigo-600) -->
        <div class="w-10 h-10 text-indigo-600">
            @Icon
        </div>
        <!-- Title: 20px semibold, slate-900 -->
        <h3 class="text-xl font-semibold text-slate-900">@Title</h3>
        <!-- Description: 16px normal, slate-600 -->
        <p class="text-base text-slate-600 leading-relaxed">@Description</p>
    </div>
</div>

@code {
    [Parameter, EditorRequired] public MarkupString Icon { get; set; }
    [Parameter, EditorRequired] public string Title { get; set; } = string.Empty;
    [Parameter, EditorRequired] public string Description { get; set; } = string.Empty;
}
```

Notes:
- `MarkupString` is the correct Blazor type for inline SVG (raw HTML markup)
- `EditorRequired` attribute provides design-time warnings if props omitted
- Padding: py-12 (48px) vertical, px-6 (24px) horizontal — per UI-SPEC 2xl vertical, lg horizontal
- All Tailwind classes match UI-SPEC color and typography spec
